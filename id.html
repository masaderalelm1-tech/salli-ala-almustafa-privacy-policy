Kebijakan Privasi Aplikasi Salli Ala Almustafa ﷺ

Aplikasi Salli Ala Almustafa ﷺ tidak mengumpulkan, meminta, atau menyimpan informasi pribadi apa pun yang dapat digunakan untuk mengidentifikasi pengguna, seperti:

  • Nama.
  • Alamat email.
  • Nomor telepon.
  • Lokasi geografis.
  • Kontak.
  • Foto pribadi.
  • Pesan.

Pengguna tidak perlu membuat akun atau masuk untuk menggunakan layanan utama aplikasi.

Untuk meningkatkan pengalaman pengguna, aplikasi dapat menyimpan beberapa pengaturan pada perangkat pengguna, seperti:

  • Preferensi pengguna.

Data tersebut disimpan di penyimpanan khusus aplikasi dan tidak dapat diakses oleh aplikasi lain.

Aplikasi menggunakan koneksi internet hanya untuk tujuan berikut:

  • Menyinkronkan konten dengan server.
  • Mengunduh atau memperbarui teks, gambar, audio, atau video ketika pembaruan tersedia.
  • Meningkatkan konten yang ditampilkan dalam aplikasi.

Koneksi internet tidak digunakan untuk mengumpulkan informasi pribadi pengguna.

Aplikasi dapat mengunduh beberapa file audio atau media dan menyimpannya di penyimpanan khusus aplikasi agar dapat diputar dengan efisien. File-file tersebut tidak dibagikan kepada pihak ketiga mana pun.
