Kebijakan Privasi Salli Ala Almustafa ﷺ

Terakhir diperbarui: 27 Juli 2026

Selamat datang di aplikasi Salli Ala Almustafa ﷺ. Kami berkomitmen untuk melindungi privasi pengguna. Kebijakan Privasi ini menjelaskan bagaimana aplikasi menangani informasi dan data selama Anda menggunakan aplikasi.

1. Informasi yang Dikumpulkan oleh Aplikasi

Aplikasi Salli Ala Almustafa ﷺ tidak mengumpulkan, meminta, atau menyimpan informasi pribadi yang dapat digunakan untuk mengidentifikasi pengguna, seperti:

  • Nama.
  • Alamat email.
  • Nomor telepon.
  • Lokasi geografis.
  • Kontak.
  • Foto pribadi.
  • Pesan.

Aplikasi tidak mengharuskan pengguna membuat akun atau masuk untuk menggunakan layanan utamanya.

2. Data yang Disimpan Secara Lokal

Aplikasi menyimpan beberapa pengaturan secara lokal di perangkat pengguna untuk meningkatkan pengalaman penggunaan, seperti:

  • Suara pengingat yang dipilih.
  • Pengaturan pengingat.
  • Preferensi pengguna.
  • Beberapa file media yang diunduh untuk digunakan di dalam aplikasi.

Data tersebut disimpan di dalam ruang penyimpanan pribadi aplikasi dan tidak dapat diakses oleh aplikasi lain.

3. Koneksi Internet

Aplikasi menggunakan koneksi Internet hanya untuk tujuan berikut:

  • Menyinkronkan konten dengan server.
  • Mengunduh atau memperbarui teks, gambar, audio, atau video ketika pembaruan tersedia.
  • Meningkatkan konten yang ditampilkan di dalam aplikasi.

Koneksi Internet tidak digunakan untuk mengumpulkan informasi pribadi pengguna.

4. Notifikasi

Aplikasi menggunakan notifikasi lokal untuk mengingatkan pengguna agar berselawat kepada Nabi ﷺ sesuai dengan pengaturan yang dipilih oleh pengguna.

Aplikasi tidak mengirimkan notifikasi iklan atau pemasaran.

5. File dan Audio

Aplikasi dapat mengunduh file audio tertentu atau media lainnya dan menyimpannya di dalam ruang penyimpanan pribadi aplikasi agar dapat diputar dengan efisien.

File-file tersebut tidak dibagikan kepada pihak ketiga.

6. Layanan Pihak Ketiga

Aplikasi menggunakan beberapa layanan teknis yang diperlukan untuk pengoperasiannya, seperti:

  • Supabase untuk menyimpan dan menyinkronkan konten.

Layanan tersebut tidak digunakan untuk menjual data pengguna atau membagikannya untuk tujuan periklanan.

7. Perlindungan Data

Kami mengambil langkah-langkah yang sesuai untuk melindungi data yang digunakan oleh aplikasi dan berupaya meminimalkan jumlah data yang disimpan hanya sebatas yang diperlukan untuk menjalankan aplikasi.

8. Privasi Anak

Aplikasi ini sesuai untuk semua kelompok usia dan kami tidak dengan sengaja mengumpulkan informasi pribadi dari anak-anak.

9. Berbagi Data

Salli Ala Almustafa ﷺ tidak menjual, menyewakan, atau membagikan data pribadi pengguna kepada pihak ketiga.

10. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui ketika fitur baru ditambahkan atau ketika terdapat persyaratan hukum atau peraturan baru.

Setiap pembaruan akan dipublikasikan di halaman ini bersama dengan tanggal pembaruan terbaru.
