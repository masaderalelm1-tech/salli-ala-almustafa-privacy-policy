Welcome to Pray for Al-Mustafa ﷺ. We are committed to protecting user privacy, and this policy explains how the application handles information and data during usage.

1. Information Collected by the App

The Pray for Al-Mustafa ﷺ app does not collect, request, or store any personal data that can identify the user, such as:

  • Name
  • Email address
  • Phone number
  • Geographical location
  • Contacts
  • Personal photos
  • Messages

Furthermore, the application does not require account creation or login to access its core services.

2. Data Stored Locally

The app saves certain preferences locally on the user's device solely to improve the user experience, including:

  • Selected reminder sound
  • Reminder settings
  • User preferences
  • Downloaded media files used within the app

This data is stored isolated within the app's private local storage and cannot be accessed by other applications.

3. Internet Connection Usage

The app uses the internet connection strictly for the following purposes:

  • Synchronizing content with the server.
  • Downloading or updating texts, images, audio, or video files when updates are available.
  • Enhancing the in-app displayed content.

Internet connectivity is never used to harvest or gather personal user data.

4. Notifications

The application uses local notifications to remind users to pray upon the Prophet ﷺ according to the preferences configured by the user. No promotional or marketing notifications are sent.

5. Files and Audio Handling

The application may download certain audio or media files and store them in internal app storage for smooth performance. These files are never shared with any external third parties.

6. Third-Party Services

The app relies on essential backend technology services to function correctly, specifically:

  • Supabase: Used for hosting and synchronizing content.

These services are never used to sell user data or share information for advertising purposes.

7. Data Security

We implement appropriate measures to safeguard app-related data, keeping stored information strictly to the minimum required for core app operation.

8. Children's Privacy

The app is suitable for all age groups and does not knowingly collect any personal data from children.

9. Data Sharing

The Pray for Al-Mustafa ﷺ application does not sell, rent, or share user data with any third parties.

10. Changes to This Privacy Policy

This Privacy Policy may be updated periodically when adding new features or in response to new legal/regulatory requirements. Any updates will be published on this page with an updated revision date.

11. Contact Us
