Privacy Policy for Salli Ala Almustafa ﷺ

Welcome to the Salli Ala Almustafa ﷺ application. We are committed to protecting the privacy of our users. This Privacy Policy explains how the application handles information and data while you use the application.

1. Information We Collect

Salli Ala Almustafa ﷺ does not collect, request, or store personal information that can be used to identify the user, including:

  • Name.
  • Email address.
  • Phone number.
  • Geographical location.
  • Contacts.
  • Personal photos.
  • Messages.

The application does not require users to create an account or sign in to use its core services.

2. Data Stored Locally

The application stores certain settings locally on the user's device to improve the user experience, such as:

  • The selected reminder sound.
  • Reminder settings.
  • User preferences.
  • Some media files downloaded for use within the application.

These data are stored within the application's private storage area and are not accessible to other applications.

3. Internet Connection

The application uses an Internet connection only for the following purposes:

  • Synchronizing content with the server.
  • Downloading or updating texts, images, audio files, or videos when updates are available.
  • Improving the content displayed within the application.

The Internet connection is not used to collect personal information about the user.

4. Notifications

The application uses local notifications to remind users to send prayers upon the Prophet Muhammad ﷺ according to the settings selected by the user.

The application does not send advertising or marketing notifications.

5. Files and Audio

The application may download certain audio files or other media and store them within the application's private storage area so that they can be played efficiently.

These files are not shared with any third party.

6. Third-Party Services

The application relies on certain technical services necessary for its operation, such as:

  • Supabase for storing and synchronizing content.

These services are not used to sell user data or share user data for advertising purposes.

7. Data Protection

We take appropriate measures to protect the data used by the application and work to minimize the amount of stored data to the minimum necessary for operating the application.

8. Children's Privacy

The application is suitable for users of all age groups. We do not knowingly collect personal information from children.

9. Data Sharing

Salli Ala Almustafa ﷺ does not sell, rent, or share users' personal information with any third party.

10. Changes to This Privacy Policy

This Privacy Policy may be updated when new features are added or when new legal or regulatory requirements arise.

Any updates will be published on this page together with an updated revision date.
