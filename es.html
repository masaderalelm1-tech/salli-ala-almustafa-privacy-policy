Política de Privacidad de la aplicación Salli Ala Almustafa ﷺ

Bienvenido a la aplicación Salli Ala Almustafa ﷺ. Nos comprometemos a proteger la privacidad de nuestros usuarios. Esta Política de Privacidad explica cómo la aplicación gestiona la información y los datos durante su uso.

1. Información que recopila la aplicación

La aplicación Salli Ala Almustafa ﷺ no recopila, solicita ni almacena información personal que pueda utilizarse para identificar al usuario, como:

  • Nombre.
  • Dirección de correo electrónico.
  • Número de teléfono.
  • Ubicación geográfica.
  • Contactos.
  • Fotografías personales.
  • Mensajes.

No es necesario crear una cuenta ni iniciar sesión para utilizar las funciones básicas de la aplicación.

2. Datos almacenados localmente en el dispositivo

Para mejorar la experiencia del usuario, la aplicación almacena algunas configuraciones únicamente en el dispositivo del usuario, entre ellas:

  • Sonido seleccionado para los recordatorios.
  • Configuración de los recordatorios.
  • Preferencias del usuario.
  • Algunos archivos multimedia descargados para utilizarse dentro de la aplicación.

Estos datos se almacenan en el espacio de almacenamiento privado de la aplicación y no pueden ser accedidos por otras aplicaciones.

3. Conexión a Internet

La aplicación utiliza la conexión a Internet únicamente para los siguientes fines:

  • Sincronizar el contenido con el servidor.
  • Descargar o actualizar textos, imágenes, audios o vídeos cuando haya actualizaciones disponibles.
  • Mejorar el contenido mostrado dentro de la aplicación.

La conexión a Internet no se utiliza para recopilar información personal del usuario.

4. Notificaciones

La aplicación utiliza notificaciones locales para recordar al usuario que envíe bendiciones al Profeta Muhammad ﷺ, de acuerdo con la configuración elegida por el propio usuario.

La aplicación no envía notificaciones publicitarias ni de marketing.

5. Archivos y audio

La aplicación puede descargar determinados archivos de audio u otros contenidos multimedia y almacenarlos en el espacio de almacenamiento privado de la aplicación para permitir una reproducción eficiente. Estos archivos no se comparten con terceros.

6. Servicios de terceros

La aplicación utiliza algunos servicios tecnológicos necesarios para su funcionamiento, entre ellos:

  • Supabase para almacenar y sincronizar contenido.

Estos servicios no se utilizan para vender los datos de los usuarios ni para compartirlos con fines publicitarios.

7. Protección de datos

Adoptamos medidas adecuadas para proteger los datos utilizados por la aplicación y procuramos reducir la cantidad de datos almacenados al mínimo necesario para el funcionamiento de la aplicación.

8. Privacidad de los niños

La aplicación es adecuada para usuarios de todas las edades y no recopila intencionadamente información personal de los niños.

9. Compartición de datos

La aplicación Salli Ala Almustafa ﷺ no vende, alquila ni comparte la información personal de los usuarios con terceros.

10. Cambios en la Política de Privacidad

Esta Política de Privacidad puede actualizarse cuando se añadan nuevas funciones o cuando existan nuevos requisitos legales o reglamentarios.

Cualquier actualización se publicará en esta página junto con la actualización de la fecha de la última modificación.

11. Contacto

Correo electrónico: contact@masadereducation.com
