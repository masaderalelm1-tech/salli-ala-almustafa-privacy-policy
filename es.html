Política de Privacidad de Salli Ala Almustafa ﷺ

Última actualización: 27 de julio de 2026

Bienvenido a la aplicación Salli Ala Almustafa ﷺ. Nos comprometemos a proteger la privacidad de nuestros usuarios. Esta Política de Privacidad explica cómo la aplicación gestiona la información y los datos durante su uso.

1. Información recopilada por la aplicación

La aplicación Salli Ala Almustafa ﷺ no recopila, solicita ni almacena información personal que pueda utilizarse para identificar al usuario, como:

  • Nombre.
  • Dirección de correo electrónico.
  • Número de teléfono.
  • Ubicación geográfica.
  • Contactos.
  • Fotografías personales.
  • Mensajes.

La aplicación no requiere crear una cuenta ni iniciar sesión para utilizar sus servicios básicos.

2. Datos almacenados localmente

La aplicación almacena determinados ajustes localmente en el dispositivo del usuario para mejorar su experiencia, como:

  • El sonido seleccionado para los recordatorios.
  • La configuración de los recordatorios.
  • Las preferencias del usuario.
  • Algunos archivos multimedia descargados para su uso dentro de la aplicación.

Estos datos se almacenan en el espacio de almacenamiento privado de la aplicación y no son accesibles para otras aplicaciones.

3. Conexión a Internet

La aplicación utiliza una conexión a Internet únicamente para los siguientes fines:

  • Sincronizar el contenido con el servidor.
  • Descargar o actualizar textos, imágenes, archivos de audio o vídeos cuando haya actualizaciones disponibles.
  • Mejorar el contenido mostrado dentro de la aplicación.

La conexión a Internet no se utiliza para recopilar información personal sobre el usuario.

4. Notificaciones

La aplicación utiliza notificaciones locales para recordar al usuario que envíe bendiciones al Profeta ﷺ, de acuerdo con la configuración seleccionada por el propio usuario.

No se envían notificaciones publicitarias ni de marketing.

5. Archivos y audio

La aplicación puede descargar determinados archivos de audio u otros contenidos multimedia y almacenarlos dentro del espacio de almacenamiento privado de la aplicación para permitir su reproducción de manera eficiente.

Estos archivos no se comparten con terceros.

6. Servicios de terceros

La aplicación utiliza determinados servicios técnicos necesarios para su funcionamiento, entre ellos:

  • Supabase para almacenar y sincronizar contenido.

Estos servicios no se utilizan para vender los datos de los usuarios ni para compartirlos con fines publicitarios.

7. Protección de datos

Tomamos medidas adecuadas para proteger los datos utilizados por la aplicación y trabajamos para reducir al mínimo la cantidad de datos almacenados necesaria para el funcionamiento de la aplicación.

8. Privacidad de los niños

La aplicación es adecuada para usuarios de todas las edades y no recopila conscientemente información personal de niños.

9. Compartición de datos

Salli Ala Almustafa ﷺ no vende, alquila ni comparte los datos personales de los usuarios con terceros.

10. Cambios en esta Política de Privacidad

Esta Política de Privacidad puede actualizarse cuando se añadan nuevas funciones o cuando surjan nuevos requisitos legales o reglamentarios.

Cualquier actualización se publicará en esta página junto con una nueva fecha de modificación.
