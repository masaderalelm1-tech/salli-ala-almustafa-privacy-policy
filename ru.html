Политика конфиденциальности приложения Salli Ala Almustafa ﷺ

Добро пожаловать в приложение Salli Ala Almustafa ﷺ. Мы стремимся защищать конфиденциальность наших пользователей. Настоящая Политика конфиденциальности объясняет, каким образом приложение обрабатывает информацию и данные во время его использования.

1. Информация, собираемая приложением

Приложение Salli Ala Almustafa ﷺ не собирает, не запрашивает и не хранит персональную информацию, которая может использоваться для идентификации пользователя, включая:

  • Имя.
  • Адрес электронной почты.
  • Номер телефона.
  • Данные о местоположении.
  • Контакты.
  • Личные фотографии.
  • Сообщения.

Для использования основных функций приложения не требуется создание учетной записи или вход в систему.

2. Данные, хранящиеся на устройстве

Приложение сохраняет некоторые настройки непосредственно на устройстве пользователя для улучшения работы и удобства использования, в том числе:

  • Выбранный звук напоминания.
  • Настройки напоминаний.
  • Пользовательские предпочтения.
  • Некоторые медиафайлы, загруженные для использования внутри приложения.

Эти данные хранятся в защищенном хранилище приложения и недоступны другим приложениям.

3. Подключение к Интернету

Приложение использует подключение к Интернету только для следующих целей:

  • Синхронизация содержимого с сервером.
  • Загрузка или обновление текста, изображений, аудио- или видеоматериалов при наличии обновлений.
  • Улучшение содержимого, отображаемого в приложении.

Интернет-соединение не используется для сбора персональной информации о пользователях.

4. Уведомления

Приложение использует локальные уведомления, чтобы напоминать пользователю о необходимости произносить салават Пророку ﷺ в соответствии с выбранными пользователем настройками.

Приложение не отправляет рекламные или маркетинговые уведомления.

5. Файлы и аудиоматериалы

Приложение может загружать определенные аудиофайлы и другие медиафайлы и сохранять их во внутреннем хранилище приложения для эффективного воспроизведения. Эти файлы не передаются третьим лицам.

6. Сторонние сервисы

Для обеспечения работы приложение использует определенные технические сервисы, включая:

  • Supabase для хранения и синхронизации содержимого.

Эти сервисы не используются для продажи данных пользователей или их передачи в рекламных целях.

7. Защита данных

Мы принимаем соответствующие меры для защиты данных, используемых приложением, и стремимся свести объем хранимых данных к минимуму, необходимому для работы приложения.

8. Конфиденциальность детей

Приложение подходит для пользователей всех возрастных групп и не осуществляет намеренный сбор персональной информации о детях.

9. Передача данных

Приложение Salli Ala Almustafa ﷺ не продает, не сдает в аренду и не передает персональную информацию пользователей каким-либо третьим лицам.

10. Изменения в настоящей Политике конфиденциальности

Настоящая Политика конфиденциальности может быть обновлена при добавлении новых функций или возникновении новых законодательных или нормативных требований.

Все изменения будут опубликованы на этой странице с указанием обновленной даты последнего изменения.
