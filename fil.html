Patakaran sa Privacy ng Salli Ala Almustafa ﷺ

Huling na-update: Hulyo 27, 2026

Maligayang pagdating sa Salli Ala Almustafa ﷺ. Pinahahalagahan namin ang privacy ng aming mga gumagamit. Ipinapaliwanag ng patakarang ito kung paano namin pinangangasiwaan ang impormasyon at data habang ginagamit ang application.

1. Impormasyong Kinokolekta ng Application

Ang Salli Ala Almustafa ﷺ ay hindi nangongolekta, humihingi, o nag-iimbak ng anumang personal na impormasyon na maaaring gamitin upang makilala ang gumagamit, tulad ng:

  • Pangalan.
  • Email address.
  • Numero ng telepono.
  • Lokasyon.
  • Mga contact.
  • Mga personal na larawan.
  • Mga mensahe.

Hindi kinakailangan ng application na gumawa ng account o mag-log in upang magamit ang mga pangunahing serbisyo nito.

2. Data na Nakaimbak sa Device

Ang application ay nagse-save ng ilang setting sa device ng gumagamit lamang upang mapahusay ang karanasan sa paggamit, tulad ng:

  • Napiling tunog para sa mga paalala.
  • Mga setting ng paalala.
  • Mga kagustuhan ng gumagamit.
  • Ilang media file na dina-download upang magamit sa loob ng application.

Ang data na ito ay iniimbak sa pribadong storage ng application at hindi maaaring ma-access ng ibang applications.

3. Koneksyon sa Internet

Gumagamit ang application ng internet para lamang sa mga sumusunod na layunin:

  • Pag-synchronize ng content sa server.
  • Pag-download o pag-update ng mga teksto, larawan, audio, o video kapag may available na mga update.
  • Pagpapahusay ng content na ipinapakita sa application.

Hindi ginagamit ang koneksyon sa internet upang mangolekta ng personal na impormasyon tungkol sa gumagamit.

4. Mga Notification

Gumagamit ang application ng mga lokal na notification upang paalalahanan ang gumagamit na magpadala ng salawat kay Propeta Muhammad ﷺ, ayon sa mga setting na pinili mismo ng gumagamit.

Walang ipinapadalang advertising o marketing notification.

5. Mga File at Audio

Maaaring mag-download ang application ng ilang audio o media file at i-save ang mga ito sa pribadong storage ng application upang mahusay na mapatugtog ang mga ito.

Ang mga file na ito ay hindi ibinabahagi sa anumang third party.

6. Mga Third-Party Service

Gumagamit ang application ng ilang teknikal na serbisyo na kinakailangan para sa operasyon nito, tulad ng:

  • Supabase — para sa pag-iimbak at pag-synchronize ng content.

Ang mga serbisyong ito ay hindi ginagamit upang ibenta ang data ng gumagamit o ibahagi ito para sa advertising.

7. Proteksyon ng Data

Gumagawa kami ng naaangkop na mga hakbang upang maprotektahan ang data na ginagamit ng application at sinisikap naming bawasan ang dami ng data na iniimbak sa pinakamababang antas na kinakailangan upang mapatakbo ang application.

8. Privacy ng mga Bata

Ang application ay angkop para sa lahat ng edad at hindi sinasadyang nangongolekta ng personal na impormasyon mula sa mga bata.

9. Pagbabahagi ng Data

Ang Salli Ala Almustafa ﷺ ay hindi nagbebenta, nagpapaupa, o nagbabahagi ng personal na data ng gumagamit sa anumang third party.

10. Mga Pagbabago sa Patakaran sa Privacy

Maaaring baguhin o i-update ang patakarang ito kapag nagdagdag ng mga bagong feature o kapag may mga bagong legal o regulatory requirement.

Ang anumang update ay ilalathala sa pahinang ito kasama ang bagong petsa ng huling pagbabago.
