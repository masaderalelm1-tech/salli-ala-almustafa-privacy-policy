Patakaran sa Privacy ng Salli Ala Almustafa ﷺ

Maligayang pagdating sa Salli Ala Almustafa ﷺ application. Pinahahalagahan namin ang pagprotekta sa privacy ng aming mga user. Ipinapaliwanag ng Patakaran sa Privacy na ito kung paano pinangangasiwaan ng application ang impormasyon at data habang ginagamit ito.

1. Impormasyong Kinokolekta ng Application

Ang Salli Ala Almustafa ﷺ application ay hindi nangongolekta, humihingi, o nag-iimbak ng anumang personal na impormasyon na maaaring gamitin upang makilala ang user, kabilang ang:

  • Pangalan.
  • Email address.
  • Numero ng telepono.
  • Lokasyon o geographic location.
  • Mga contact.
  • Mga personal na larawan.
  • Mga mensahe.

Hindi kinakailangang gumawa ng account o mag-log in upang magamit ang mga pangunahing serbisyo ng application.

2. Data na Lokal na Iniimbak sa Device

Upang mapahusay ang karanasan ng user, ang application ay nag-iimbak ng ilang setting nang direkta sa device ng user, tulad ng:

  • Napiling tunog para sa mga paalala.
  • Mga setting ng paalala.
  • Mga preference ng user.
  • Ilang media file na dina-download upang gamitin sa loob ng application.

Ang data na ito ay iniimbak sa pribadong storage ng application at hindi ito maaaring ma-access ng ibang applications.

3. Koneksyon sa Internet

Ginagamit lamang ng application ang koneksyon sa Internet para sa mga sumusunod na layunin:

  • Pag-synchronize ng content sa server.
  • Pag-download o pag-update ng mga text, larawan, audio, o video kapag may available na update.
  • Pagpapahusay ng content na ipinapakita sa application.

Hindi ginagamit ang Internet connection upang mangolekta ng personal na impormasyon ng user.

4. Mga Notification

Gumagamit ang application ng local notifications upang paalalahanan ang user na magpadala ng salawat para sa Propeta Muhammad ﷺ, ayon sa mga setting na pinili mismo ng user.

Hindi nagpapadala ang application ng anumang advertising o marketing notifications.

5. Mga File at Audio

Maaaring mag-download ang application ng ilang audio file o iba pang media content at i-save ang mga ito sa pribadong storage ng application upang mahusay na ma-play ang mga ito. Hindi ibinabahagi ang mga file na ito sa anumang third party.

6. Mga Third-Party Service

Gumagamit ang application ng ilang teknikal na serbisyo na kinakailangan para sa pagpapatakbo nito, kabilang ang:

  • Supabase para sa pag-iimbak at pag-synchronize ng content.

Hindi ginagamit ang mga serbisyong ito upang ibenta ang data ng user o ibahagi ito para sa mga layunin ng advertising.

7. Proteksyon ng Data

Gumagawa kami ng naaangkop na mga hakbang upang maprotektahan ang data na ginagamit ng application at sinisikap naming panatilihin ang dami ng nakaimbak na data sa pinakamababang antas na kinakailangan para sa pagpapatakbo ng application.

8. Privacy ng mga Bata

Ang application ay angkop para sa mga user sa lahat ng edad at hindi sadyang nangongolekta ng personal na impormasyon mula sa mga bata.

9. Pagbabahagi ng Data

Ang Salli Ala Almustafa ﷺ application ay hindi nagbebenta, nagpapaupa, o nagbabahagi ng personal na impormasyon ng user sa anumang third party.

10. Mga Pagbabago sa Patakaran sa Privacy

Maaaring i-update ang Patakaran sa Privacy na ito kapag nagdagdag ng mga bagong feature o kapag may mga bagong legal o regulatory requirements.

Ang anumang update ay ilalathala sa pahinang ito at ia-update din ang petsa ng huling pagbabago.
